## About the project

This project makes the Hack computer draw a black box on the screen while any key is held down. When the key is released, the box disappears. It is built in three parts:

1. **Build the computer:** the CPU, Memory and Computer chips, written in HDL and tested with the official test files.
2. **Write an assembler:** a Python program that translates Hack assembly (`.asm`) into 16-bit machine code (`.hack`).
3. **Write the box program:** `Box.asm`, converted with my own assembler and run in the CPU Emulator.

## How the assembler works

- **First pass:** removes comments, spaces and blank lines, and records each label such as `(LOOP)` as the address of the next real instruction.
- **Second pass:** converts every line to 16 bits.
  - An A-instruction becomes `0` followed by a 15-bit number.
  - A name is looked up in the predefined symbols, then in the labels. Any other name is a new variable and gets a RAM address starting at 16.
  - A C-instruction becomes `111` + comp + dest + jump, using lookup tables.
- **Extra feature (K mod 3 = 0):** after assembling, every label and variable is written with its address to `symbols.txt`.

## How to run

Assemble any program:

```
python assembler.py Box.asm
```

This creates `Box.hack` and `symbols.txt`. The same command works for `Add.asm`, `Max.asm`, `Rect.asm` and `Pong.asm`.

To see the box, open the CPU Emulator from the Nand to Tetris tools, load `Box.hack`, enable the keyboard, run the program, and hold down any key.

## How Box.asm works

1. Read the keyboard. If a key is pressed, set `color` to -1 (black), otherwise set it to 0 (white).
2. Set `addr` to 19168 (the first word of row 87) and `rows` to 20.
3. For each row, write `color` into 4 words (64 pixels), add 32 to `addr` to reach the next screen row, and decrease `rows`.
4. When `rows` reaches 0, go back to step 1 and check the key again.

Releasing the key makes the same loop write white, so the box disappears.
