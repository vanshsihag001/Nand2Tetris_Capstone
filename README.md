## What this project does

This project makes the Hack computer show a black box on the screen while any key is held down. When the key is released, the box disappears. It has three parts:

1. **Build the computer** – CPU, Memory and Computer chips written in HDL.
2. **Write an assembler** – a Python program that converts Hack assembly (`.asm`) into machine code (`.hack`).
3. **Write the box program** – `Box.asm`, assembled with my own assembler and run on the computer.

| `Box.asm` | Box program in Hack assembly |
| `Box.hack` | Box program assembled by `assembler.py` |
| `symbols.txt` | Labels and variables with addresses, generated by the assembler |

## How the assembler works

- **First pass:** removes comments and blank lines, and records each label such as `(LOOP)` as the address of the next instruction.
- **Second pass:** converts each line to 16 bits. A-instructions become binary numbers, new variables get RAM addresses from 16 upward, and C-instructions are built as `111` + comp + dest + jump.
- **Extra feature:** writes every label and variable with its address to `symbols.txt`.

## How to run

Assemble a program:

```
python assembler.py Box.asm
```

This creates `Box.hack` and `symbols.txt`.

To see the box, open the **CPU Emulator** from the Nand to Tetris software suite, load `Box.hack`, set the keyboard to enabled, run the program, and hold down a key.

## How Box.asm works

The program loops forever and reads the keyboard. If a key is pressed it sets `color` to -1 (black), otherwise to 0 (white). It then writes `color` into 4 words on each of 20 rows, adding 32 to the address after each row to move to the next screen row.
